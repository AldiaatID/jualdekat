# Assets

Tempatkan asset gambar berikut di folder ini untuk build:

- `icon.png` (1024x1024)
- `adaptive-icon.png` (1024x1024)
- `splash.png` (~1242x2436)
- `favicon.png` (48x48)

Selama development, Expo akan men-fallback ke ikon default jika file belum ada.
Asset placeholder dapat di-generate via `npx expo-asset` atau diganti nanti saat
proses branding final.
